# CNCOC Service Builder

The web page the song leader uses to put together the Sunday and Wednesday service PowerPoint for Central North Church of Christ.

This repository holds only the page itself (`index.html`, the deck generator `gen.js`, and the church's transition slides in `deck-data.js`). The hymn pictures, chorus words and hymn catalogue are private: the page fetches them from the church's Google Apps Script after it is opened with the access key from the members' page of the church website.

Published with GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
